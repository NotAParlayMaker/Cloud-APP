# Changelog - SportsInsight AI v2.0.0

## [2.0.0] - 2026-01-09

### 🎉 Major Release: SportsInsight AI - Premium Features Launch

Transitioning from OpenSportsAnalytics (open-source) to **SportsInsight AI** (freemium SaaS platform).

### Added - Premium Features

#### 💰 Subscription System
- Three-tier pricing: Free, Premium ($19/mo), Pro ($99/mo)
- Usage tracking and tier-based limits
- Subscription management endpoints

#### 🤖 AI Chat Assistant
- Natural language sports queries
- Player predictions, injury risk, comparisons
- 100 queries/month (Premium), Unlimited (Pro)

#### 📱 Mobile API
- Mobile-optimized endpoints
- Push notification support
- Quick stats and predictions

#### ⚡ Real-Time Features
- Live game updates
- WebSocket subscriptions
- Play-by-play data

#### 🏈 Fantasy & Betting
- DFS lineup optimizer
- Betting odds and analysis
- Fantasy league integrations

#### 👥 Social Features
- User predictions and voting
- Community leaderboards
- Discussions and profiles
